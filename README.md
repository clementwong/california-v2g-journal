# The Potential and Viability of V2G for California BEV Drivers: Simulation and Analysis Codebase

## 1. Overview

This repository contains the code and data accompanying the manuscript:

> 
> **"The potential and viability of V2G for California EV drivers"** (Wong, Trewartha, Torrisi, & Filipowicz, 2026).
> 
> 

Questions related to the data and/or analyses can be directed to: clemwong@umich.edu

### Code
Notebooks required to reproduce the figures and analyses for the article are found in the `./notebooks/` directory.

Functions to superimpose our user-centric V2G strategy (outlined in Section 2.1) onto vehicle usage profiles and apply the battery degradation models (outlined in Section 3.3 and Supplementary Note 1) are found in the `./src/` directory.

### Data 
Data generated by simulations and used in our figures and analyses are located in the `./data/` directory. To adhere to standard file size limits, the data is split between this GitHub repository and an Open Science Framework (OSF) repository.

* **Simulation Results of 10-year Capacity Loss without and with out user-centric V2G strategy (Included in Repository):** 
  `./data/california_bev_battery_degradation_simulation_results.csv`

* **Example Synthetic Vehicle Usage Data (Hosted on OSF):**
  * **Download Link:** [OSF Repository: Synthetic Vehicle Usage Data](https://osf.io/7jqfr/overview?view_only=71248e44aecf4dfa8f31415d20974f34)
  * **Setup Instruction:** To run the notebooks locally, download the `synthetic_vehicle_usage` folder from the OSF link above and place them directly into the `./data/` folder of your cloned repository.


## 2. Repository Structure

```text
├── data/
│   ├── california_bev_battery_degradation_simulation_results.csv # Estimated 10-year capacity loss (total, calendar, and cycle) across battery designs and vehicle usage
│   └── synthetic_vehicle_usage/
│       ├── daily_charger.parquet 
│       ├── public_charger.parquet
│       ├── bev_second_vehicle.parquet
│       └── threshold_charger.parquet
        # Synthetic 10-year time-series usage (SOC, C-rate) data for each of four identified Californian vehicle usage behavior profiles for V2G Assessment
├── src/
│   ├── battery_model.py   # Battery degradation models (Section 3.3 and Supplementary Note 1)
│   └── v2g_strategy.py    # Superimposes the user-centric V2G strategy onto usage profiles (Section 2.1)
├── notebooks/
│   ├── apply_battery_model.ipynb            # Demonstration of applying battery model to usage data
│   ├── example_vehicle_usage_behaviors.ipynb # Visualization of vehicle usage behaviors
│   └── generate_result_figures_and_analyses.ipynb        # Reproduces manuscript figures analyses
│   └── generate_SI_data_analyses.ipynb        # Reproduces data analyses shown in SI
├── requirements.txt   
└── README.md

```

## 3. System Requirements

* **Python:** 3.9 or higher.
* **Installation:** Install required dependencies via `pip install -r requirements.txt`.
